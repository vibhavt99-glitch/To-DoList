# To-Do List in C++

A simple console-based To-Do List application written in C++ that allows users to add, view, and manage daily tasks on Windows.

## 🚀 Features

- Add new daily tasks
- Display all current tasks
- Mark tasks as completed or delete them

## 🛠️ Tech Stack

- **Language:** C++
- **IDE:** VS Code (with Code Runner extension)
- **OS:** Windows

## 💻 How to Run in VS Code (Windows)

### Prerequisites
1. **VS Code** installed on Windows.
2. **C/C++ Extension** by Microsoft installed in VS Code (`Ctrl + Shift + X` ➔ search `C/C++`).
3. **Code Runner Extension** installed in VS Code (`Ctrl + Shift + X` ➔ search `Code Runner`).
4. A C++ compiler installed (like **MinGW** / GCC for Windows).

### Running the Program

1. Open the project folder in VS Code (`File ➔ Open Folder ➔ To-DoList`).
2. Open `todolist.cpp`.
3. Click the **Play ▶ button** in the top-right corner of VS Code (or press `Ctrl + Alt + N`).

> 💡 **Note for Interactive Input:** If your program takes user input (`cin`) and Code Runner shows a read-only error in the Output window, enable terminal integration:
> Go to **File ➔ Preferences ➔ Settings**, search for `code-runner.runInTerminal`, and check the box for **"Run In Terminal"**.
